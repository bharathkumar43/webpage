# Kabini.ai Landing Page

A modern, responsive React landing page for Kabini.ai - Make Your Store Seen in AI Platforms.

## Features

- **Modern React Architecture** - Built with React 18 and functional components
- **Responsive Design** - Mobile-first approach with beautiful animations
- **Interactive Components** - FAQ accordion, animated counters, ripple effects
- **Performance Optimized** - Efficient rendering and smooth animations
- **Accessibility** - Proper ARIA labels and keyboard navigation

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.

## Key Components

### Hero Section
- Animated typing effect for the main headline
- AI platform badges with hover effects
- Call-to-action button with ripple animation

### Solutions Grid
- 6 solution cards with hover animations
- Feature lists with checkmark icons
- Responsive grid layout

### Results Section
- Animated counters that trigger on scroll
- Gradient background with pattern overlay
- Glass-morphism effect cards

### FAQ Section
- Accordion functionality with smooth animations
- Expandable/collapsible questions
- Visual feedback for open/closed states

### Interactive Features
- Scroll-to-top button
